Penfold

한국어English日本語简体中文

Mac で動くコーディングエージェント(Claude Code、Codex)を、iPhone から確認・返信・新規起動。

エージェントは机の上の Mac で働かせたまま、どれが終わったか、どれが返事を待っているかをスマホで確認し、その場で返信できます。iPhone は Tailscale 経由で、SSH で Mac に直接つながります。

iPhone アプリは App Store での公開を準備中です。スクリーンショットは韓国語版で、アプリの表示言語は韓国語と英語です。

Herdr 専用です。 Penfold に表示されるのは Herdr の中で起動したエージェントだけです。ターミナル.app や iTerm で直接起動した claude・codex は表示されません。Herdr のタブか Penfold の ＋ から起動してください。macOS 専用で、Mac が起きている必要があります。

できること

返事が必要なものを先にスペースごとにまとめ、何分待っているかも表示します。
チャットとして読めるツール呼び出しは 1 行にまとまり、変更ファイルは +追加 −削除 のカードで表示。
権限リクエストに即答選択肢をタップするだけ。Mac の前にいなくても大丈夫。
通知エージェントが返事を待っているときや終わったときに知らせます。
新しい作業を始めるMac のフォルダを選び、ボタンひとつで Claude Code や Codex を起動。
写真・ファイル・音声添付や音声入力に対応。IME の文字は確定してからまとめて送ります。

仕組み

iPhone · Penfold→ Tailscale + SSH →自分の Mac→Herdr→Claude Code / Codex

間に Penfold のサーバーはありません。SSH 鍵は iPhone 上で作成してキーチェーンに保管し、Mac のホスト鍵はペアリング時に固定します。

必要なもの

  • 席を離れている間も起きている Mac(macOS)— 電源につないでおいてください
  • Herdr と、インストール・ログイン済みの Claude Code または Codex
  • Mac と iPhone の両方に Tailscale(同じアカウント)

Mac の準備

Mac のターミナルに次の 1 行を貼り付けてください。1 ステップずつ確認し、足りないものはインストールを手伝います(インストール前に必ず確認します)。メッセージは韓国語か英語で表示されます。

curl -fsSL https://raw.githubusercontent.com/SihyunAdventure/penfold-mac/main/setup | zsh
  1. 開発者ツール(python3)
  2. Tailscale — インストール・ログイン・オン
  3. リモートログイン(SSH)
  4. Herdr と、Claude Code または Codex の確認
  5. 通知 — エージェントの作業中は Mac をスリープさせません
  6. ペアリング — ターミナルに QR コードが表示されます

iPhone をつなぐ

  1. iPhone で Tailscale をオンにします。
  2. Mac のターミナルの QR を iPhone のカメラで読み取ります。
  3. Penfold が開いたら Connect をタップします。

Mac がなくても、最初の画面の Try without a Mac で、すべての画面をサンプルで試せます。

よくある質問

エージェントが一覧に出てきません。 表示されるのは Herdr の中で起動したものだけです。Herdr のタブで起動し直してください。Mac に Claude Code か Codex がインストール・ログインされている必要があります。

Mac につながりません。 両方の端末で Tailscale がオンで同じアカウントか、Mac がスリープしていないかを確認してください。Settings › Connection status で、どの段階で止まっているかがわかります。

通知が来ません。 Settings › Alerts で、この iPhone の許可、Mac の通知デーモン、登録状態を確認し、テスト通知を送ってみてください。

コードや会話がどこかに送られますか? いいえ。アプリは自分の Mac とだけ通信します。詳しくはプライバシーポリシーをご覧ください。
