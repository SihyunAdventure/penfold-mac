Penfold

한국어English日本語简体中文

在 iPhone 上查看、回复、启动你 Mac 上的编程智能体(Claude Code、Codex)。

让智能体在桌上的 Mac 里继续工作,用手机看到哪些已经完成、哪些在等你回复,并随时随地回复。iPhone 通过 Tailscale,用 SSH 直接连接你的 Mac。

iPhone 应用正在准备上架 App Store。截图为韩语版,应用界面支持韩语和英语。

仅支持 Herdr。 Penfold 只显示在 Herdr 中运行的智能体,直接在“终端”或 iTerm 里启动的 claude、codex 不会显示。请在 Herdr 标签页中启动,或使用 Penfold 的 ＋。仅支持 macOS,且 Mac 需要保持唤醒。

功能

优先显示需要你的按空间分组,并标出每个智能体已等待多久。
像聊天一样阅读工具调用折叠成一行,修改的文件显示为 +新增 −删除 卡片。
直接回复权限请求点一下选项即可,不必守在 Mac 前。
通知智能体等待回复或完成工作时通知你的 iPhone。
开始新工作选择 Mac 上的文件夹,一个按钮启动 Claude Code 或 Codex。
照片、文件、语音可附加或语音输入。输入法文字确认后整段发送。

工作原理

iPhone · Penfold→ Tailscale + SSH →你的 Mac→Herdr→Claude Code / Codex

中间没有 Penfold 服务器。SSH 密钥在 iPhone 上生成并保存在钥匙串中,Mac 的主机密钥在配对时固定。

准备条件

  • 一台在你离开时也保持唤醒的 Mac(macOS)——请接上电源
  • Herdr,以及已安装并登录的 Claude Code 或 Codex
  • Mac 和 iPhone 都安装 Tailscale,并使用同一账号

准备 Mac

在 Mac 的终端中粘贴下面这一行。它会逐步检查,并帮你安装缺少的内容(安装前总会先询问)。提示信息为韩语或英语。

curl -fsSL https://raw.githubusercontent.com/SihyunAdventure/penfold-mac/main/setup | zsh
  1. 开发者工具(python3)
  2. Tailscale —— 安装、登录、开启
  3. 远程登录(SSH)
  4. Herdr,并检查 Claude Code 或 Codex
  5. 通知 —— 智能体工作期间让 Mac 保持唤醒
  6. 配对 —— 终端中会显示二维码

连接 iPhone

  1. 在 iPhone 上开启 Tailscale。
  2. 用 iPhone 自带的相机扫描 Mac 终端中的二维码。
  3. Penfold 打开后点 Connect。

没有 Mac?在首屏点 Try without a Mac,即可用示例智能体体验所有界面。

常见问题

列表里没有我的智能体。 只显示在 Herdr 中运行的智能体。请在 Herdr 标签页中重新启动。Mac 上需要安装并登录 Claude Code 或 Codex。

连不上 Mac。 确认两台设备都开启了 Tailscale 且使用同一账号,并且 Mac 没有睡眠。Settings › Connection status 会显示卡在哪一步。

收不到通知。 在 Settings › Alerts 中检查本机是否允许通知、Mac 的通知守护进程以及注册状态,然后发送一条测试通知。

我的代码或对话会被发送到别处吗? 不会。应用只与你自己的 Mac 通信。详见隐私政策。
