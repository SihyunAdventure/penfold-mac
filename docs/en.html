Penfold

한국어English日本語简体中文

Watch, answer and start the coding agents (Claude Code, Codex) on your Mac — from your iPhone.

Leave the agents working at your desk. Penfold shows which ones are done and which are waiting for you, and lets you reply from wherever you are. The iPhone connects to your Mac directly over SSH, through Tailscale.

The iPhone app is getting ready for the App Store. Screenshots show the Korean version; the app is in English and Korean.

Works with Herdr only. Penfold shows agents running inside Herdr, not ones started straight from Terminal or iTerm. Start them in a Herdr tab or with the ＋ button in Penfold. macOS only; the Mac has to be awake.

How it works

iPhone · Penfold→ Tailscale + SSH →Your Mac→Herdr→Claude Code / Codex

There's no Penfold server in the middle. The SSH key is created on the iPhone and kept in its Keychain; the Mac's host key is pinned when you pair.

What you need

  • A Mac (macOS) that stays awake while you're away — keep it plugged in
  • Herdr, plus Claude Code or Codex installed and logged in
  • Tailscale on both the Mac and the iPhone, same account

Set up the Mac

Paste this into the Mac's Terminal. It checks one step at a time and helps install what's missing (it always asks first).

curl -fsSL https://raw.githubusercontent.com/SihyunAdventure/penfold-mac/main/setup | zsh
  1. Developer tools (python3)
  2. Tailscale — install, log in, turn on
  3. Remote Login (SSH)
  4. Herdr, and a check for Claude Code or Codex
  5. Alerts — keeps the Mac awake while agents work
  6. Pairing — a QR code appears in Terminal

Pair your iPhone

  1. Turn on Tailscale on the iPhone.
  2. Scan the QR in the Mac's Terminal with the iPhone's Camera app.
  3. Penfold opens — tap Connect.

No Mac? Tap Try without a Mac on the first screen to try every screen with sample agents.

FAQ

My agent isn't in the list. Only agents running inside Herdr show up. Restart it in a Herdr tab. Claude Code or Codex has to be installed and logged in on the Mac.

Penfold can't reach the Mac. Check that Tailscale is on on both devices with the same account, and that the Mac isn't asleep. Settings › Connection status shows which step is failing.

No alerts. In Settings › Alerts, check that this iPhone is allowed, the Mac's alert daemon is running and the device is registered, then send a test alert.

Do my code or conversations go anywhere? No. The app talks only to your Mac. See the privacy policy.
