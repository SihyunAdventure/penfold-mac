개인정보처리방침

시행일 2026년 11월 2일

Penfold는 개인정보를 수집하지 않아요. 계정, 분석 도구, 광고, 추적이 없어요. 에이전트 목록, 대화, 코드, 터미널 화면은 개발자가 운영하는 서버로 보내지 않아요. 유일한 예외는 알림이에요(아래 '알림'에서 설명해요).

앱이 연결하는 곳

앱은 사용자가 연결한 사용자 본인의 Mac에만 SSH로 직접 연결해요(보통 Tailscale 네트워크를 거쳐요). 에이전트 목록, 대화 내용, 터미널 화면, 보내는 메시지·사진·파일은 이 연결로만 오가고, 그 외 어디에도 저장되거나 전송되지 않아요.

iPhone에 저장하는 것

  • Mac 접속 정보(호스트 이름, 사용자 이름, Mac의 호스트 키): 앱 설정에 저장돼요.
  • SSH 키: 앱이 iPhone에서 만들고 Keychain에 보관해요. 개인 키는 iPhone 밖으로 나가지 않아요.
  • 작성 중인 메시지 초안: iPhone에만 저장돼요.

권한

  • 카메라·사진: 사용자가 고른 사진을 에이전트에게 보낼 때만 써요. 사진은 사용자의 Mac으로만 가요.
  • 마이크·음성 인식: 받아쓰기로 메시지를 입력할 때만 써요. 음성 인식은 Apple의 음성 인식 기능이 처리해요.
  • 로컬 네트워크: Mac에 SSH로 연결하는 데 써요.
  • 알림: 에이전트가 답을 기다리거나 작업을 마쳤을 때 알려 줘요. 알림을 켜면 앱이 iPhone의 알림 토큰을 개발자가 운영하는 알림 중계 서버(penfold-relay)에 보내 확인값을 받고, 토큰과 확인값은 사용자의 Mac에 저장돼요. 알림이 생기면 Mac이 토큰과 알림 내용(에이전트 이름, 스페이스, 권한을 요청한 명령 같은 짧은 상태 한 줄)을 중계 서버로 보내고, 중계 서버는 이를 Apple 푸시 알림 서비스(APNs)로 전달만 해요. 중계 서버는 토큰과 알림 내용을 저장하지 않아요. 알림을 허용하지 않으면 토큰이 만들어지지 않아 중계 서버로 아무것도 가지 않아요.

데모 모드

Mac 없이 둘러보기는 앱 안의 예시 데이터만 써요. 아무 곳에도 연결하지 않아요.

Privacy Policy (English)

Effective November 2, 2026. Penfold collects no personal data: no accounts, analytics, ads or tracking. Agent lists, conversations, code and terminal screens are never sent to servers run by the developer; the one exception is alerts, described below. The app connects only to the user's own Mac over SSH (usually through Tailscale); agent lists, conversations, terminal screens and the messages, photos and files the user sends travel only over that connection. Connection settings and drafts stay on the iPhone; the SSH key is created on the iPhone and kept in the Keychain. Camera, photos, microphone and speech recognition are used only when the user attaches a photo or dictates a message. When alerts are on, the app sends the iPhone's notification token to the developer's alert relay (penfold-relay) to get a ticket, and the token and ticket are stored on the user's Mac. When an alert is due, the Mac sends the token and the alert text (agent name, space and a one-line status, such as the command waiting for permission) to the relay, which only passes it on to Apple Push Notification service. The relay does not store tokens or alert text. If alerts are never allowed, no token is created and nothing reaches the relay. The demo mode uses sample data inside the app and connects nowhere.
